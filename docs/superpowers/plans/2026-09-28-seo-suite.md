# SEO Suite nativo

## Objetivo

Implementar issue #71 como o primeiro consumidor completo do Plugin SDK.

## Tarefas

1. Criar domínio SEO test-first para metadata, canonical, JSON-LD, sitemap, robots e redirects.
2. Criar `SeoService` com leitura dos options/meta existentes e migrar sitemap/robots/metadata para ele.
3. Transformar `seo-optimizer` em `NodePressPlugin`, registrar menu/slot e remover o filtro legado que alterava conteúdo.
4. Integrar metadata de posts, páginas e landing pages, além do breadcrumb slot público.
5. Documentar o contrato, executar testes, typecheck, lint e build; então abrir PR referenciando #71.

## Verificação

- `npm test`
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- Nenhum teste deve encontrar a assinatura antiga ou alteração de `postContent`.
